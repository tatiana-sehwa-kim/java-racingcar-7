# java-racingcar-precourse

자동차 경주 게임을 구현한다.  

⭐ 입력 기능
- [ ] 경주할 자동차 이름을 입력받는다.
- [ ] 시도할 횟수를 입력받는다.

⭐ 자동차 이름 유효성 검사 및 데이터 처리
- [ ] 쉼표(,)를 기준으로 자동차 이름 분리
- [ ] 각 자동차의 초기 이동 거리를 0으로 매핑하여 저장한다.
- [ ] [예외] 자동차 이름의 길이가 5를 넘거나 공백이면 IllegalArgumentException을 띄운다.
- [ ] [예외] 게임횟수가 0이거나 음수일 경우 IllegalArgumentException을 띄운다.
- [ ] [예외] 게임횟수가 숫자가 아닐 경우 IllegalArgumentException을 띄운다.
- [ ] 입력받은 시도 횟수를 정수형으로 변환한다.
- 

⭐ 경주 진행
- [ ] 0부터 9의 랜덤값을 던져 4 이상일 경우 전진한다.
- [ ] 매 라운드마다 자동차 이름과 이동 거리(-) 출력
- [ ] 라운드 종료 시 빈 줄 출력

⭐ 우승자 발표
- [ ] 우승자는 가장 멀리 이동한 자동차 이름을 출력한다.
- [ ] 우승자가 2명 이상일 경우 쉼표(,)와 함께 출력한다.
